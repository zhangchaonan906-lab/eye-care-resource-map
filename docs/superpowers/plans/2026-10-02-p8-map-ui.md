# P8 Map UI Implementation Plan

Branch: `p8-map-ui` from merged P7 `main` (`b6c14f1`).

## Scope

Implement `/resources/eye-hospitals` with MapLibre, the existing P7 public APIs, accessible list/detail/search/filter interactions, responsive layout, explicit non-production basemap placeholder, cancellation-safe viewport loading and client-side clustering. Do not add geolocation, nearby queries, navigation, admin, imports, or production basemap URLs.

## Steps

1. Inspect the P7 API contracts and existing build/test setup; add MapLibre and UI test dependencies.
2. Add shared category/API UI contracts and an explicit development basemap provider configuration with no external tile URLs.
3. Implement the page shell and responsive components: search/filters, map, facility list, detail panel, location placeholder.
4. Implement viewport API loading with debounce, abort/stale-response protection, cursor pagination safety cap, min-zoom suppression, and explicit incomplete/error/empty states.
5. Implement MapLibre adapter with local blank style, GeoJSON clustering, marker/cluster selection, and no network requests.
6. Add React UI/component tests for API states, cancellation, filters, map/list selection, detail/search/category behavior, accessibility, and sensitive-field exclusion.
7. Add P8 documentation; run UI/unit tests, TypeScript, ESLint, Next build, DB regression if available, and `git diff --check`.
8. Commit, push `p8-map-ui`, open the requested PR, and report its CI status.
