## 项目用途说明

拟建设医疗资源检索与地图展示系统“全国眼科医疗资源地图”，帮助用户查询眼科相关医疗资源。申请数据将用于项目内部标准化、去重、来源审计和医院基本信息展示，并在另行确认合法地理编码及所需权限后用于地图展示。系统将标明数据来源，并保留从展示记录追溯到获批数据来源的能力。

项目承诺的处理边界：

- 不出售原始数据。
- 不公开原始数据文件，不提供原始数据库下载。
- 不绕过平台访问控制、登录要求、申请流程或其他技术限制。
- 只处理获批的数据集和字段，并按批准的地区、用途、应用和期限使用。
- 建立来源追踪和访问权限控制，并按数据提供方要求支持停止使用、撤回和删除。
- 遵循最小权限原则，仅由确有工作需要的人员访问原始文件。
- 不申请或处理个人信息、患者数据、医生个人数据，或与本项目无关的个人字段。

项目运营主体及资金来源：〔由申请主体如实填写，不作推定〕
