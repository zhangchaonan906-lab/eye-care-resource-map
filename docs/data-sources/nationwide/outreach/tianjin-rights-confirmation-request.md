# 关于“三级医疗机构基本信息”数据使用条件的咨询函

致：天津市信息资源统一开放平台 / 天津市卫生健康委数据提供部门

您好：

我们正在筹建“全国眼科医疗资源地图”，用于医疗资源检索、医院信息展示和来源追溯，并计划在取得相应授权后开展地图定位。项目不会出售官方原始数据，也不会公开原始数据文件或数据库 dump。

贵平台数据集“三级医疗机构基本信息”页面标注为无条件开放。为准确遵守该数据集及平台的使用要求，烦请协助确认以下事项：

1. **长期保存与内部处理：** 项目能否将人工下载的官方 XLS 存入项目数据库长期保存，并用于内部整理、审计和必要的数据处理？是否有保存期限或安全要求？
2. **公开网站展示：** 项目能否在公开 Web/App 地图中展示由该文件整理得到的医院名称、地址、类别等必要字段？展示前是否需要另行审批或备案？
3. **商业使用：** 商业化网站或产品是否可以在上述范围内使用该数据？如无商业用途限制，也烦请明确说明。
4. **定期更新与历史版本：** 项目能否定期人工重新下载更新版本，并为来源审计保留历史版本？如可以，历史版本是否有保留期限？
5. **下架、撤回或政策变更：** 数据集下架、撤回或平台政策更新后，已合法取得的原始副本是否必须删除？由其生成的派生数据是否也必须删除？是否有过渡期或其他处置要求？
6. **额外程序：** 下载或使用是否需要登录账户、提交申请、备案或取得其他审批？
7. **署名：** 使用时要求的准确署名文本是什么？应放在地图详情、数据来源说明页或其他什么位置？
8. **人工下载：** 项目只进行人工下载，不进行自动爬取或自动化访问；这种获取方式是否允许？

如有适用的数据集说明、使用条款或办理指引，也烦请提供对应的官方链接或文件。我们会依据贵方回复决定是否继续使用该来源；在权利条件明确前不会下载、导入或公开使用该数据集。
