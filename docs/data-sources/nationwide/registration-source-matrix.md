# P6-N1 全国医疗机构执业登记来源发现矩阵

检索日期：2026-10-01。范围为大陆 31 个省级规划单元。本矩阵是官方来源发现的首轮结果，不是穷尽性证明，也不构成来源批准、下载授权、全国覆盖声明或导入许可。每一条“未找到”均表示本轮检索没有核实到符合条件的具体数据集页；不代表地区没有此类数据。

## 发现口径

- 只采用政府、卫健委及政府公共数据开放平台页面、目录或官方文件。没有使用第三方镜像、登录、验证码、私有接口或隐藏 API。
- `province_wide`、`city_only`、`district_only` 仅按数据集页面明确的地域范围或名称范围记录；区域完整率仍需来源明确说明或文件核验。来源未说明地域时记 `unknown`。
- `有`表示官方页面/文件明确提供；`未核实`不是“没有”。诊疗科目/许可项目只有在官方描述明确指出该字段时才标为有。
- 下载格式被官方目录列出不等于本次已下载或验证文件可匿名取得。出现登录入口时，若访客能否下载未验证，登录要求记“未核实”。
- “无条件开放”仅为平台当前页面所标注的开放属性，不替代项目对长期保存、公开展示、商用、撤回后副本处置等权利的核验；本轮新增来源均保持 `source_status=UNKNOWN`。

## 天津已验证模式

先前人工取得并只读预演的天津官方 XLSX 为 36 行，确切检查字段为 `批准时间、机构名称、地址、诊疗科目、床位数、类别、所有制形式`；其中 4 行、4 个名称出现来源明确的眼科证据。该文件不是本轮新下载；当前矩阵来源名称对应西青区登记数据的开放计划线索，覆盖记 `district_only`。行数与含有多区名的地址不能用来证明天津市全量覆盖。

## 本轮计数与结论

- 检索范围：大陆 31 个省级规划单元；官方门户、卫健委数据公开/目录、公开搜索页和政府公开文件首轮检索。
- 官方执业登记/许可数据集或具体目录线索：至少 8 项；另发现多个行政许可公告、查询页和医保名单，它们单列为查询/批次材料，不算全量登记数据集。
- 官方描述中同时明确名称、地址和诊疗科目的现行/近年候选：6 项（达州 1、广州 2、夷陵 2、西青区先前实文件 1）；上海旧目录另有 1 项历史线索但已 stale。
- 明确可核实的文件线索：3 个当前官方详情页列出文件下载类型（达州、攀枝花、宜昌市医院信息），天津西青另有此前已取得的官方文件；广州 2 项只有官方开放计划中的格式说明，当前详情页/下载按钮尚未确认。上海 Excel 仅为历史目录线索，不计入当前文件候选。
- 明确需要申请：1 条已有项目线索（浙江“二级及以上医疗机构基本信息”）；尚无申请/审批。
- 全国各地登记字段组合可从开放目录开始逐地复制检查；天津证明诊疗科目字段可做来源证据，但当前样本只证实区级试点可行，不能证明全国普遍公开或全省覆盖。

## 来源边界 / 后续权利审查

不得把医保定点名录、医院等级统计、行政许可公告、医疗机构查询页统称为“医疗机构执业登记全量库”。对每一条来源，在下载前仍要确认所给数据集条款、范围、格式、数据日期、anonymous download 是否成立，以及长期保存/地图展示/商用/署名/撤回后处置。后续若获得真实文件，仅允许先做文件 provenance 与本地 schema inspect；本轮没有下载、导入、访问 geocoder、发布 facility 或更改来源批准状态。
