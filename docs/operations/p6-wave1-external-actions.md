# P6 Wave 1 外部动作清单

本清单只列需要项目负责人手工办理的外部动作。任何来源在取得明确授权前均不得下载或导入真实数据。

## 天津

- **Contact:** 天津市信息资源统一开放平台官方咨询渠道；如需转交，联系天津市卫生健康委数据提供部门。请从[数据集详情页](https://open.data.tj.gov.cn/sjj/1be22c6e54be4f3e85989bc60ae28bd8.htm)或[平台网站声明页](https://open.data.tj.gov.cn/xgxx/wzsm/index.htm)进入平台公开联系渠道，不使用未经核实的私人联系方式。
- **Send:** [天津权利确认函](../data-sources/nationwide/outreach/tianjin-rights-confirmation-request.md)，填写真实联系人后提交。
- **Await:** 对长期保存、内部处理、公开 Web/App 展示、商业使用、历史版本保留、下架/撤回处置、登录/申请要求、署名和人工下载逐项作出的官方回复。

## 河北

- **Contact:** 河北省公共数据开放平台、河北省数据和政务服务局或河北省医疗保障局的官方公开咨询渠道。
- **Send:** [河北来源位置询问函](../data-sources/nationwide/outreach/hebei-source-location-request.md)，询问“河北省医保局‘定点医疗机构信息表’目前在哪个官方公共数据平台发布？”，并请求详情页 URL 与使用条件。
- **Await:** 可访问的河北官方 dataset detail page、提供主体、开放属性、字段/地区/更新说明、下载方式和适用协议。不要从京津冀目录下载替代。

## 浙江

- **Platform:** [浙江省数据开放平台](https://data.zjzwfw.gov.cn/dopServer/index.html)。
- **Submit:** 由真实申请主体人工核实并填写[数据使用申请草稿](../data-sources/nationwide/applications/zhejiang-data-use-application-draft.md)，在平台申请对应数据集；本清单不表示已提交申请。
- **Await:** 正式批准文件及项目具体协议，确认主体、数据提供方、数据集/字段/地区、期限、处理、公开展示、商业使用、派生数据、更新、撤回/销毁、署名、安全责任和联系人。
